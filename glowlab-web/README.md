# glowlab-web

GlowLab web app (React 18 + Vite + TypeScript): auth, project list, the photo
Designer (upload or Demo House, trace/calibrate, glowing preset bulbs, icicle
drops, night mode), live estimate panel, and a printable Quote view.

`npm install && npm run build` — output in `dist/`, served by `@glowlab/server`.
Dev: `npm run dev` (proxies `/api` to localhost:4200).
